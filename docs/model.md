# 数値モデル τ_θ（`src/lib/society/model.ts`）

Science Utopia は、研究制度 θ を入力に取り、AI 研究者社会の 1 年分の応答（指標）を返す関数 τ_θ を 5 回呼ぶゲームです。
θ を研究者がスイープすれば実験になり、プレイヤーが 1 年ずつ選べばゲームになります。同じ関数を別の形で呼んでいるだけです。

- 決定論的: `seed` と θ の系列が同じなら結果も同じ（PRNG は mulberry32、年ごとに `seed ^ year·0x9e3779b1` で初期化）。
- LLM はニュース・研究者の声・講評の**文章だけ**を書きます。数値には関与しません。
- 1 年の計算は 1〜2 ms です（24 人・論文数百本）。
- 定数はすべて `model.ts` の `C` にあります。

## θ（6 次元）

| キー | 値 | 意味 |
|---|---|---|
| `funding_frac` | 0.05 / 0.3 / 1.0 | 資金を受け取る研究者の割合（総額は固定） |
| `acceptance` | 0.1 / 0.3 / 0.6 | 採択率（投稿数に対する採択数の割合） |
| `incentive` | citations / replication / novelty | 評価指標（引用数 / 再現性・検証 / 新規性） |
| `verify` | none / spot / all | 検証義務（なし / 抜き打ち / 全件） |
| `youth_share` | elders / neutral / youth | 人材（大御所に厚く / 中立 / 若手に厚く） |
| `islands` | mono / two / multi | 多元性（一極 / 2 島 / 多島＋交流） |

初期値（現状維持）: `funding_frac=0.3, acceptance=0.3, incentive=citations, verify=none, youth_share=elders, islands=two`。

## 1 年の手順

1. **分野の移動**: `mono` では全体で最大の分野へ、`two` では同じ島の最大の分野へ、確率 `herd` で移ります（引用数評価では ×1.3、新規性評価では ×0.6）。`multi` では確率 0.08 でランダムな別分野へ移ります（交流）。
2. **資金**: 順位スコア（elders: 評判＋年長加点、youth: 0.3·評判＋若手加点、neutral: 評判）の上位 `round(N_active·funding_frac)` 人で総額 N を等分します。
3. **投稿**: 研究者ごとに Poisson(λ)、λ = (0.8 + 1.1·√funding) × 採択率倍率 × 検証倍率 × 評価倍率。√ なので集中させるほど総投稿数は減ります。
4. **論文の性質**
   - 偽の確率 = min(0.6, (0.04 + 0.3·(1−誠実さ)) × 圧力)。圧力 = 評価倍率 × 採択率倍率 × (1 − 0.6·検出率) で、検出率が高いと抑止がかかります。
   - 新規性 = 0.4 + 評価補正 + 若手補正 + 交流補正 − 0.3·max(0, 分野シェア − 1/6) + 0.15·N(0,1) + (偽なら +0.15、誇張)。
5. **査読**: 偽の論文は確率 `detect + 0.2·(0.3 − acceptance)` で見抜かれて不採択になり、著者の評判が下がります（2 回で退場）。残りを「新規性 + 評判バイアス·評判 + ノイズ」で並べ、`round(acceptance·投稿数)` 本を採択します。評判バイアスは elders 0.35 / neutral 0.2 / youth 0.1 です。
6. **引用**: 採択 1 本あたり 6 回の引用が起こります。引用先は既存の採択論文から重み (1+被引用)^α · (0.3+新規性) · 分野親和性 · 0.7^経過年 で選びます。α は citations 1.1 / novelty 0.6 / replication 0.4 で、引用数評価では富者がさらに富みます。再現性評価のときは偽の論文の重みが ×0.3 になり、出版後にも 30% の確率で偽が見つかります。
7. **評判と離脱**: 評判 = 0.75·評判 + 0.25·(今年の被引用/最大値) + 0.03·採択数 − 0.12·摘発数。資金がなく評判が 0.3 未満の研究者は、確率 0.1（採択率 0.1 のときは 0.25）で離脱します。

## 指標（SUTO と同じ名前）

| 指標 | 定義 |
|---|---|
| `papers` | その年の投稿数 |
| `accepted` | その年の採択数 |
| `citations` | その年に起きた引用の数 |
| `Gini` | 研究者ごとの累積被引用数の Gini 係数 |
| `H` | その年の採択論文の分野分布のエントロピー（bit、最大 log₂6 ≈ 2.585） |
| `hit` | 採択された真の論文のうち、新規性 0.65 以上の本数 |
| `fraud_rate` | 採択論文のうち偽の割合 |
| `pluralism` | 在籍研究者の分野分布の有効数（exp(H_nat)）÷ 6 |

## エンディング（5 年目の後）

優先順位: 枯渇 > モノカルチャー > 引用カルテル > ユートピア。

- **枯渇**: 在籍が 65% 未満、または最終年の採択が 6 本未満
- **モノカルチャー**: 最終年の pluralism が 0.45 未満
- **引用カルテル**: 最終年の Gini が 0.6 以上で、かつ上位 3 人の被引用シェアが 45% 以上
- **ユートピア**: 上のどれにも当たらない

## 方向性テスト（`model.test.ts`）

40 seed × 5 年でプールした値で、次の大小関係を固定しています。

- 資金を集中させると Gini は上がり、papers は下がる
- 全件検証にすると fraud も papers も下がる
- 採択を寛容にすると papers も fraud も上がる
- 引用数評価は再現性評価より Gini が高く、fraud も高い
- 新規性評価は再現性評価より hit が多い
- 多島＋交流は一極より H も pluralism も高い
- 若手に厚くすると大御所に厚くするより hit が多い
- 4 種のエンディングにはすべて到達できる

これらは「この形のモデルならこうなる」というおもちゃの性質であり、現実の科学についての主張ではありません。
